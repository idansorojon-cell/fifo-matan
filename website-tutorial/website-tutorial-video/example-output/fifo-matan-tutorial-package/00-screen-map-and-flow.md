# מפת מסכים וזרימה — FIFO PRO (מתן)

**כתובת:** https://idansorojon-cell.github.io/fifo-matan/
**קהל יעד:** משתמש חדש (מתן) שרואה את המערכת לראשונה
**נבדק דרך:** preview server מקומי, session מחובר בפועל

## זרימה טבעית של משתמש חדש

1. **מסך התחברות** — שם משתמש + סיסמה
2. **Cockpit** (מסך הבית ברירת המחדל) — ברכה אישית, שווי כולל, "אין פעולות דחופות", כרטיס AI Coach קצר
3. **דשבורד (מהניווט העליון)** — KPIs מלאים + 3 גרפים (Equity Curve, רווח לפי חודש, Drawdown)
4. **מסחר → היסטוריית עסקאות** — טבלת כל העסקאות, כולל תגיות Long/Short/Option
5. **מסחר → פוזיציות פתוחות** — כרטיסי פוזיציה עם מחיר חי
6. **ניתוח → תובנות** — KPIs מתקדמים (streaks, Sharpe, Kelly וכו')
7. **בינה מלאכותית → AI Coach** — ניתוח דפוסי מסחר
8. **הגדרות** — אבטחה, יעדים, Viewer

## הערות מהמפוי בפועל

- מסך ברירת המחדל אחרי login הוא **Cockpit**, לא "דשבורד" — חשוב לפתוח שם, לא בטעות ב-דשבורד
- כל טבלאות העסקאות/פוזיציות מציגות תגיות **Long/Short/Option** ליד שם הסימבול — זו הנקודה הכי ייחודית להסביר
- 0 פוזיציות פתוחות כרגע אצל מתן — אם זה משתנה, שווי לעדכן את הסקרינשוט המתאים
